# ROOT-derived numerical primitives

The standalone four-vector and random helpers use the calibration behavior of the Atlas Externals build of ROOT 6.40.02. The upstream tag `v6-40-02` resolves to the ROOT commit below. ROOT is distributed under GNU LGPL 2.1 or later. This directory retains that license and notices for the adapted routines. ROOT itself is not a runtime dependency of these headers. [ROOT license](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/LICENSE)

- Cylindrical four-vectors preserve GenVector's signed mass, operation order, cylindrical phi restriction, Cartesian eta conversion, and singular eta encoding. [PtEtaPhiM4D](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/genvector/inc/Math/GenVector/PtEtaPhiM4D.h) · [PxPyPzE4D](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/genvector/inc/Math/GenVector/PxPyPzE4D.h) · [Eta conversion](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/genvector/inc/Math/GenVector/eta.h)
- Cartesian reconstruction and truth angular distance preserve the legacy TLorentzVector and TVector3 operations. [TLorentzVector](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/physics/inc/TLorentzVector.h) · [TVector3](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/physics/src/TVector3.cxx) · [TVector2](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/physics/src/TVector2.cxx)
- The deterministic stream implements the positive-seed TRandom3 MT19937 behavior and the TRandom acceptance-complement Gaussian. ATLAS substitutes a positive fallback when its seed calculation truncates to zero. ROOT's nondeterministic zero-seed API is outside the portable stage contract. [TRandom](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/mathcore/src/TRandom.cxx) · [TRandom3](https://github.com/root-project/root/blob/d4c0003542952bec9c4edc86c419784a32875e9d/math/mathcore/src/TRandom3.cxx)
